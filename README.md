A Digital Library Management System built with Java 21, Hibernate ORM, and JPA. 
The project demonstrates a layered architecture using Entity, Repository, and Service layers with PostgreSQL database integration.

Features:
- Manage books with CRUD operations
- Store book information including title, ISBN, publication year, price, stock status, and publisher address
- Use JPA/Hibernate for ORM and database persistence
- Implement Generic Repository Pattern
- Implement Service Layer with business validation
- Custom exception handling
- Transaction management using reusable Hibernate infrastructure
- Entity lifecycle demonstration (Transient, Managed, Detached, and Merge states)
- Automatic ID generation using PostgreSQL Sequence strategy

Technologies:
- Java 21
- Hibernate ORM 7
- Jakarta Persistence API (JPA)
- PostgreSQL
- Maven
